A repeatable way to answer interview questions

Coding / DSA

Clarify inputs and constraints → propose a simple solution → optimize → state complexity → test edge cases → write clean code.

System design

Clarify requirements → estimate scale → define APIs and data → draw components → trace critical flows → address failures, security, and trade-offs.

Behavioral: STAR + learning

Situation and task → your specific actions → measurable result → what you learned or would improve. Say “I” for your contribution and “we” for team outcomes.

Technical explanation

Define the concept → explain why it matters → give a concrete example → name a limitation or alternative. State assumptions instead of guessing.
