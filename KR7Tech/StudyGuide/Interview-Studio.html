2 · SQL reasoning and query review

A production endpoint needs the latest 20 orders for one customer. The table contains millions of rows. Write a parameterized query and explain the index and plan evidence you would inspect.

Schema: Orders(Id, CustomerId, CreatedAt, Status, Total). Return only the columns needed by a history list; newest first. Assume SQL Server syntax for this exercise.
This is a deterministic checklist, not a SQL engine. It does not execute your query or prove the plan is fast.

3 · Interactive system-design interview

Prompt: Customers and support agents need current order status and a history of status changes. The system starts at 2,000 requests/second peak, must isolate tenants, and should remain useful during a downstream carrier outage.

5 · Senior project deep-dive builder

Build a truthful, evidence-based project story. Use “I” for your contribution and “we” for team outcomes; never invent metrics or claim work you did not do.

Follow-up questions to rehearse: What was the hardest trade-off? What did you personally change? How did you measure impact? What failed? What would your teammate say you could have done better?
